# Data Export and FOIA

CivicLens provides a full data export system and AI-assisted FOIA (Freedom of Information Act) search across the meeting archive.

## Data Export

### Start an Export

Exports run asynchronously. Start a job and poll for completion.

```bash
# Start a JSON export (full archive)
curl -X POST https://api.civiclens.ai/api/v1/export \
  -H "X-API-Key: mra_your_key" \
  -H "Content-Type: application/json" \
  -d '{"format": "json"}'

# Start a CSV export with filters
curl -X POST https://api.civiclens.ai/api/v1/export \
  -H "X-API-Key: mra_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "format": "csv",
    "filters": {
      "date_after": "2025-01-01",
      "date_before": "2025-12-31",
      "meeting_body": "Council"
    }
  }'
```

Response:

```json
{
  "job_id": "a1b2c3d4-...",
  "tenant_id": "elk-grove",
  "status": "pending",
  "format": "json",
  "filters": {},
  "created_at": "2026-04-08T12:00:00+00:00"
}
```

### Check Export Status

```bash
curl https://api.civiclens.ai/api/v1/export/{job_id} \
  -H "X-API-Key: mra_your_key"
```

Status progresses through: `pending` -> `running` -> `completed` (or `failed`).

When completed, the response includes `file_size_bytes` and `total_meetings`.

### Download Completed Export

```bash
curl -OJ https://api.civiclens.ai/api/v1/export/{job_id}/download \
  -H "X-API-Key: mra_your_key"
```

Returns a ZIP archive. Attempting to download before the job completes returns HTTP 409.

### Export History

```bash
curl "https://api.civiclens.ai/api/v1/export/history?limit=20" \
  -H "X-API-Key: mra_your_key"
```

### Export Formats

**JSON** -- A ZIP containing one `meetings/{clip_id}/meeting.json` file per meeting, plus `transcript_segments.json` for timestamped transcript data, and a top-level `manifest.json`.

**CSV** -- A ZIP containing normalized CSV files:
- `meetings.csv` -- One row per meeting (date, title, body, topics, word count)
- `votes.csv` -- One row per motion/vote (identifier, outcome, roll call details)
- `financial_items.csv` -- Budget items, appropriations, and contracts
- `public_comments.csv` -- Speaker name, topic, and summary
- `agenda_items.csv` -- Ordinances, resolutions, and other agenda items
- `manifest.json` -- Export metadata

### Filters

All filters are optional. When omitted, the full archive is exported.

| Filter | Type | Description |
|---|---|---|
| `date_after` | `string` | ISO date lower bound (inclusive) |
| `date_before` | `string` | ISO date upper bound (inclusive) |
| `meeting_body` | `string` | Filter by meeting body name (case-insensitive substring match) |
| `keyword` | `string` | Filter by keyword in title or topics |

## FOIA Search

The FOIA endpoint uses retrieval-augmented generation to search the entire meeting archive for records responsive to a FOIA request.

### Submit a FOIA Search

```bash
curl -X POST https://api.civiclens.ai/api/v1/foia \
  -H "X-API-Key: mra_your_key" \
  -H "Content-Type: application/json" \
  -d '{"query": "All discussions and votes related to short-term rental regulations from 2024 to present"}'
```

Response:

```json
{
  "request_id": "e5f6g7h8-...",
  "tenant_id": "elk-grove",
  "query": "All discussions and votes related to short-term rental regulations...",
  "status": "pending",
  "created_at": "2026-04-08T12:00:00+00:00"
}
```

### Check FOIA Status

```bash
curl https://api.civiclens.ai/api/v1/foia/{request_id} \
  -H "X-API-Key: mra_your_key"
```

Status progresses through: `pending` -> `searching` -> `compiling` -> `completed` (or `failed`).

### FOIA Response Structure

When completed, the `result` field contains:

```json
{
  "query": "All discussions and votes related to short-term rental regulations...",
  "summary": "AI-generated narrative summarizing all findings...",
  "total_relevant_meetings": 5,
  "total_excerpts": 18,
  "findings": [
    {
      "clip_id": 6725,
      "date": "2025-03-15",
      "title": "March 15 2025 Council meeting",
      "meeting_body": "Council",
      "relevant_excerpts": [
        {
          "source": "facts",
          "text": "Ordinance 0042-25: Short-term rental licensing program...",
          "timestamp": "45:30"
        }
      ]
    }
  ],
  "searched_at": "2026-04-08T12:01:30+00:00",
  "disclaimer": "This report was generated by AI-assisted search..."
}
```

### Important Notes

- FOIA searches retrieve up to 30 chunks from the vector store for comprehensive coverage.
- The AI summary is generated by GPT-4o and includes specific details: vote counts, dollar amounts, names, and ordinance numbers.
- Every FOIA response includes a disclaimer noting that AI search may not capture all records and that a manual review is recommended for legally binding responses.
- FOIA requests are logged in the audit system for compliance tracking.
