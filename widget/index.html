Installation
Up and running in minutes
No build tools, no frameworks, no dependencies. Just add the script tag and you are done.
1

Get your API key

Create a CivicLens account and set up your tenant. Your API key will be in the Admin Dashboard under Settings.

2

Add the script tag

Copy the snippet below and paste it before the closing </body> tag on your website.

3

Customize and launch

Set your theme, accent color, position, and welcome message using data attributes. No code changes needed.

<!-- CivicLens Meeting Q&A Widget -->
<script
  src="https://cdn.civiclens.ai/widget.js"
  data-api-key="mra_your_api_key_here"
  data-api-url="https://api.civiclens.ai"
  data-theme="light"
  data-position="bottom-right"
  data-accent-color="#1a56db"
  data-title="Meeting Q&A"
  data-welcome-message="Ask anything about city council meetings."
  data-suggested-questions="What was discussed at the last council meeting?|How was the budget allocated?|Any recent zoning changes?"></script>
Configuration
Data attribute reference
Every option is set via HTML data attributes on the script tag. No JavaScript configuration needed.
Attribute Description Default
data-api-key Your tenant API key (starts with mra_) -- Required
data-api-url CivicLens API server URL -- Required
data-theme Color theme for the widget "light" Optional
data-position Corner of the screen for the widget button "bottom-right" Optional
data-accent-color Primary color (hex) for buttons, links, and header "#1a56db" Optional
data-title Header title displayed at the top of the chat panel "Meeting Q&A" Optional
data-welcome-message Greeting text shown before the first question Default welcome text Optional
data-suggested-questions Pipe-separated list of up to 3 starter questions 3 default questions Optional

Features
Everything you need, nothing you don't
The widget is a single, self-contained JavaScript file. No external dependencies, no iframes, no performance impact.
💬

Multi-Turn Chat

Citizens can ask follow-up questions in a natural conversation. Context is maintained across the session.

🎨

Shadow DOM Isolation

Styles are fully encapsulated. The widget never conflicts with your site's CSS, and vice versa.

⌨

Keyboard Accessible

Full keyboard navigation with Escape to close, Tab trapping, focus management, and ARIA attributes.

📱

Mobile Responsive

Automatically goes full-screen on small viewports. Touch-friendly controls and smooth animations.

🔎

Source Citations

Every answer includes clickable source cards with meeting date, body, and video timestamp deep-links.

💡

Suggested Questions

Show 3 configurable starter questions to help citizens discover what they can ask about.

🌈

Theming

Light and dark modes with customizable accent color. Matches any government website brand.

⚡

Typing Indicator

Animated dots with rotating status text keep users informed while the AI searches meeting records.

📄

Markdown Rendering

Responses render bold, italic, links, lists, and inline code for well-formatted answers.
