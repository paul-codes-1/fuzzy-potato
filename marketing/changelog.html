Generate PDF exports of any meeting, set up weekly email digests, and search across meetings with sub-second results.

Meeting Diff, Sentiment & Calendar Feeds

Compare how topics evolved across meetings, gauge council sentiment, and subscribe to meeting calendars directly.

Feature Meeting diff view: side-by-side comparison of how policy language changed between readings
Feature Sentiment analysis dashboard with per-topic and per-council-member breakdowns
Feature ICS calendar feeds -- subscribe to specific meeting bodies in Google Calendar or Outlook
Improvement "What's New" page highlights recent notable changes across meetings
Fix Corrected vote count display when abstentions were present

Multilingual Support, PWA & Notifications

CivicLens now speaks 5 languages, works offline as a PWA, and can push real-time alerts when topics you track come up.

Feature Full i18n: English, Spanish, French, Mandarin, and Arabic with RTL support
Feature Progressive Web App: installable, offline-capable, cached meeting data
Feature Push notifications for tracked topics, specific council members, or meeting bodies
Improvement Language switcher component with automatic locale detection
Fix Fixed accessibility announcer not working with screen readers in non-English locales

Enterprise Security & FOIA Automation

SSO/SAML for enterprise identity providers, comprehensive audit logging, and one-click FOIA request generation from any meeting record.

Feature SSO/SAML integration with Okta, Azure AD, and Google Workspace
Feature Audit logging: every query, export, and user action is tracked and exportable
Feature FOIA request automation: generate pre-filled requests from any meeting record or search result
Security SOC 2 Type II audit window opened with independent firm; penetration testing engagement in progress
Security API key rotation, IP allowlisting, and role-based access controls for admin panel

Feature Slack integration: /civiclens command to query meeting archive from any channel

Improvement Webhook notifications for new meetings, vote alerts, and agenda changes
Fix Fixed RAG citations occasionally referencing wrong clip when meetings shared similar topics

Vote Tracking & Financial Intelligence

Track every vote with roll-call detail, follow the money through budget items, and get alerts when policies you care about move forward.

Feature Financial item extraction: dollar amounts, vendors, appropriations, and contract details
Feature Policy alerts: subscribe to topics and get notified when they appear on an agenda or in a vote

Core Platform Launch
