Why IT teams choose CivicLens

Designed from day one to fit inside the constraints real government IT departments operate under — procurement cycles, data isolation, identity federation, and audit mandates.

Zero-footprint deployment

Run CivicLens as fully managed SaaS with nothing to install, or self-host the container on your own AWS or Azure. No agents on endpoints, no firewall exceptions for inbound traffic.

Works with your Granicus

CivicLens reads from your existing Granicus view IDs, clip archive, and Legistar API. No migration, no data re-upload, no disruption to clerks or councilmembers. Same video source of truth.

SSO-ready

SAML 2.0 federation with Okta, Azure AD / Microsoft Entra, Google Workspace, and any SAML-compliant IdP. Per-tenant IdP config, role-based access (admin / analyst / viewer), and email-domain restrictions.

Audit-ready

Immutable append-only audit log with SHA-256 integrity hashes on every record. Every API call, query, and admin action is tracked with tenant, user, endpoint, and duration. Exportable as CSV for your auditors.

Procurement-friendly

NASPO ValuePoint path in progress, Sourcewell and OMNIA Partners under review. We support purchase orders, multi-year contracts, COI, W-9, and complete vendor onboarding packets.

Open API

REST API with OpenAPI 3.0 schema, webhooks with HMAC signing, first-party Python and JavaScript SDKs, and an embeddable widget. Build anything you need on top — no lock-in.

Compliance alignment

Honest status on the frameworks state and local IT most often ask about. If something is in progress, we say so.

Requirement CivicLens capability
SOC 2 alignment
Trust Services Criteria
 Controls aligned to SOC 2 Type II criteria. Type II audit window in progress. Full details in the security whitepaper.
FISMA / NIST 800-53
Federal moderate baseline
 Control mapping available. FedRAMP Moderate authorization is on the roadmap for 2026. We can complete your agency's NIST 800-53 questionnaire on request.
FOIA / public records
Open government law
 Built-in FOIA request handler that searches the archive and packages responsive records as ZIP export. All CivicLens content is already publicly released government data.
ADA / WCAG 2.1 AA
Accessibility
 Frontend built to WCAG 2.1 AA. Semantic HTML, keyboard navigation, screen reader announcers, and language support in en, es, zh, vi, ko. VPAT available on request.
CJIS data considerations
Criminal justice information
 CivicLens processes publicly released council video and does not ingest CJIS-classified data. For jurisdictions with law enforcement oversight meetings, self-hosted deployment keeps all processing inside your CJIS-compliant environment.
State records retention
Schedules & holds
 Configurable retention per content type (audio, transcript, summary, embeddings). Legal hold API freezes deletion for named records. Exports align to common state retention schedules.
