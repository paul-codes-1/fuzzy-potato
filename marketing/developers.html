Quick Start

Up and running in minutes

Three examples to get you started. Pick your language and start building.

1

Ask a question about any meeting

curl -X POST https://api.civiclens.ai/api/v1/ask \
  -H "Content-Type: application/json" \
  -H "X-API-Key: mra_your_api_key_here" \
  -d '{
    "question": "What was the vote on the parks budget?",
    "filters": {
      "after": "2025-01-01",
      "body": "City Council"
    }
  }'
from civiclens import CivicLens

client = CivicLens(api_key="mra_your_api_key_here")

response = client.ask(
    question="What was the vote on the parks budget?",
    filters={
        "after": "2025-01-01",
        "body": "City Council"
    }
)

print(response.answer)
for citation in response.citations:
    print(f"  [{citation.clip_id}] {citation.timestamp}")
import { CivicLens } from '@civiclens/sdk';

const client = new CivicLens({ apiKey: 'mra_your_api_key_here' });

const response = await client.ask({
  question: 'What was the vote on the parks budget?',
  filters: {
    after: '2025-01-01',
    body: 'City Council'
  }
});

console.log(response.answer);
response.citations.forEach(c =>
  console.log(`  [${c.clip_id}] ${c.timestamp}`)
);
2

Search votes and financial items

curl "https://api.civiclens.ai/api/v1/search?q=parks+budget&type=votes" \
  -H "X-API-Key: mra_your_api_key_here"

# Response includes structured vote records:
# {
#   "results": [{
#     "identifier": "Resolution 2025-042",
#     "description": "Parks & Recreation FY26 Budget",
#     "outcome": "passed",
#     "ayes": 7, "nays": 2,
#     "votes_for": ["Adams", "Brown", "Curtis", ...],
#     "votes_against": ["Davis", "Evans"],
#     "meeting_date": "2025-03-15",
#     "clip_id": 6702
#   }]
# }
from civiclens import CivicLens

client = CivicLens(api_key="mra_your_api_key_here")

results = client.search(
    query="parks budget",
    type="votes",
    after="2025-01-01"
)

for vote in results:
    print(f"{vote.identifier}: {vote.outcome}")
    print(f"  Ayes: {vote.ayes}, Nays: {vote.nays}")
    print(f"  For: {', '.join(vote.votes_for)}")
    print(f"  Against: {', '.join(vote.votes_against)}")
import { CivicLens } from '@civiclens/sdk';

const client = new CivicLens({ apiKey: 'mra_your_api_key_here' });

const results = await client.search({
  query: 'parks budget',
  type: 'votes',
  after: '2025-01-01'
});

results.forEach(vote => {
  console.log(`${vote.identifier}: ${vote.outcome}`);
  console.log(`  Ayes: ${vote.ayes}, Nays: ${vote.nays}`);
  console.log(`  For: ${vote.votes_for.join(', ')}`);
});
3

Set up a webhook for real-time events

curl -X POST https://api.civiclens.ai/api/v1/webhooks \
  -H "Content-Type: application/json" \
  -H "X-API-Key: mra_your_api_key_here" \
  -d '{
    "url": "https://your-app.com/webhooks/civiclens",
    "events": [
      "meeting.processed",
      "vote.detected",
      "financial_item.detected"
    ],
    "secret": "whsec_your_signing_secret"
  }'

# CivicLens signs each delivery with HMAC-SHA256
# so you can verify authenticity on your end.
from civiclens import CivicLens

client = CivicLens(api_key="mra_your_api_key_here")

webhook = client.webhooks.create(
    url="https://your-app.com/webhooks/civiclens",
    events=[
        "meeting.processed",
        "vote.detected",
        "financial_item.detected"
    ],
    secret="whsec_your_signing_secret"
)

print(f"Webhook created: {webhook.id}")
print(f"Events: {', '.join(webhook.events)}")

# Verify incoming webhooks in your handler:
# from civiclens.webhooks import verify_signature
# verify_signature(payload, signature, secret)
import { CivicLens } from '@civiclens/sdk';

const client = new CivicLens({ apiKey: 'mra_your_api_key_here' });

const webhook = await client.webhooks.create({
  url: 'https://your-app.com/webhooks/civiclens',
  events: [
    'meeting.processed',
    'vote.detected',
    'financial_item.detected'
  ],
  secret: 'whsec_your_signing_secret'
});

console.log(`Webhook created: ${webhook.id}`);

API Overview

Everything you need to know

Authentication

Authenticate every request with your API key in the X-API-Key header. Keys are prefixed with mra_ and scoped to your tenant.

$ curl -H "X-API-Key: mra_abc123..." \
https://api.civiclens.ai/api/v1/health

SSO users can also authenticate via JWT Bearer tokens.

Core Endpoints

POST
/api/v1/ask

Single-turn RAG Q&A with citations

POST
/api/v1/chat

Multi-turn conversational chat with context

GET
/api/v1/search

Full-text search across meetings, votes, finances

GET
/api/v1/search/autocomplete

Typeahead suggestions for search UI

Webhooks

Get notified in real-time when meetings are processed or votes are detected. Every delivery is signed with HMAC-SHA256.

meeting.processed
meeting.summary_ready
vote.detected
financial_item.detected
query.answered

Automatic retries with exponential backoff (3 attempts). Delivery logs available via API.

Rate Limits

Limits are enforced per-tenant on a rolling 30-day window. Usage headers are included in every response.

Embeddable Widget

Drop civic intelligence
into any website

Add a CivicLens chat widget to your government website with a single script tag. Citizens can ask questions about meetings without leaving your site.

  • Customizable theme, colors, and position
  • Light and dark mode support
  • WCAG 2.1 AA accessible
  • Under 15KB gzipped
your-website.html 
<!-- Add before closing </body> tag -->
<script
  src="https://cdn.civiclens.ai/widget.js"
  data-api-key="mra_your_api_key_here"
  data-api-url="https://api.civiclens.ai"
  data-theme="light"
  data-position="bottom-right"
  data-accent-color="#1e3660"
  data-title="Ask about city meetings"
  data-welcome-message="Ask me anything about
    recent council meetings, votes, or budgets."
></script>
