1. Company Overview

Company: CivicLens, Inc.
Product: CivicLens — AI-powered civic meeting intelligence platform
Founded: 2025
Headquarters: United States
Business Model: B2G SaaS with self-hosted and managed cloud deployment options

CivicLens is a multi-tenant SaaS platform that transforms Granicus-hosted government meeting archives into searchable, queryable knowledge bases. The platform provides AI-powered transcription, structured data extraction (votes, financial items, attendance), natural-language Q&A backed by retrieval-augmented generation (RAG), sentiment analysis, and integrations with Slack, Microsoft Teams, and Zapier.

Our customers are city clerks, city managers, public-records officers, IT directors, and civic-engagement teams at municipalities that already use Granicus for meeting video hosting. We are purpose-built for local government and we do not serve enterprise customers outside the public sector.

2. Technical Architecture Summary

2.1 System Components

CivicLens is a modern Python and JavaScript application stack composed of:

  • Ingestion pipeline (Python) — scrapes Granicus clips, downloads audio, transcribes via OpenAI Whisper, extracts structured facts using GPT-4o, and generates narrative summaries using Anthropic Claude.
  • RAG API server (FastAPI) — tenant-scoped REST API for question answering, chat, search, analytics, audit, billing, webhooks, and SSO.
  • Vector store — ChromaDB with OpenAI text-embedding-3-small embeddings for semantic retrieval.
  • Relational store — SQLite for single-node deployments and PostgreSQL for production multi-instance deployments.
  • Frontend — React 18 single-page application with internationalization support (English, Spanish, Chinese, Vietnamese, Korean).
  • Embeddable widget — drop-in <script> tag for government websites.

2.2 Deployment Shapes

CivicLens supports two deployment topologies:

  • Managed cloud (recommended) — hosted by CivicLens on AWS using CloudFront for static frontend delivery and AWS App Runner for the API layer, with ACM-managed TLS certificates.
  • Self-hosted — customer runs the full stack via Docker on their own infrastructure, with all state kept under a configurable MEETINGS_OUTPUT_DIR. A documented Terraform module is provided for AWS self-deployment.

2.3 AI Model Providers

CivicLens uses commercial large-language-model APIs from OpenAI (Whisper transcription, GPT-4o extraction, text-embedding-3-small embeddings) and Anthropic (Claude for narrative summarization and chat). We do not train foundation models on customer data. Customer content sent to model providers is governed by the zero-retention data processing terms those providers offer to enterprise API customers.

3. Data Residency

In the managed cloud deployment, all CivicLens application data is stored in AWS regions within the United States. Customers with stricter residency requirements can select the self-hosted deployment option and retain full control of data location, including on-premises hosting.

CivicLens does not replicate or copy customer data outside of the region in which the tenant is provisioned, except as strictly required for disaster-recovery backups (which are also held within the same national jurisdiction).

Public meeting artifacts (video, agendas, minutes) originate from the customer's own Granicus account and are already part of the public record. CivicLens acts as a downstream processor of that already-public information.

6.1 Why Per-Org, Not Per-Seat

CivicLens is priced per organization (tenant), not per user. This is a deliberate choice: we believe civic transparency tools should not penalize governments for adding more staff or citizens to the platform. Every plan allows unlimited named users within the tenant. Query allowances are tenant-wide, not per-user.

7. References

Reference customers can be provided on request under mutual NDA. Representative customer profile:

  • City clerk or records office as the primary operational owner.

Live public demonstrations of the platform running against a real city's meeting archive are available at civiclens.ai/demo. Reference calls can be scheduled during the evaluation period.
